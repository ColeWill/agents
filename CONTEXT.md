## Purpose
A library of reusable AI agent prompts for Angular projects, visualized as a squad hierarchy on GitHub Pages. Agents are designed to work together in Kiro's agentic mode.

## How to resume work in Kiro
1. Open terminal in `/Users/cole/agents`
2. Run `kiro-cli chat`
3. The steering file at `.kiro/steering/agents-project.md` is auto-loaded — no manual setup needed

## Site structure
- `agents.json` is the single source of truth
- `agents-data.js` is auto-generated by the GitHub Actions deploy step
- `index.html` renders a Mermaid hierarchy diagram + grouped agent cards + Squad Overview flow

## Adding a new agent
1. Create `<role>.md` following the existing prompt file format
2. Add entry to `agents.json` with correct group
3. Push to main — site auto-deploys
