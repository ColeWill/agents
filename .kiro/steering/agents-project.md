## Key files
- `agents.json` — source of truth for all agent metadata (drives the site)
- `agents-data.js` — auto-generated by CI from agents.json (do not edit manually)
- `index.html` — GitHub Pages site
- `*.md` — agent prompt files
- `.kiro/steering/agents-project.md` — this file (Kiro auto-loads it)
- `CONTEXT.md` — human-readable project history and decision log

## Conventions
- Agent prompt files follow the pattern: role intro line, ## sections, Project Context override block at bottom
- To add a new agent: create `<role>.md`, add entry to `agents.json`, push to main
- Commit format: conventional commits (feat/fix/chore/docs)
- Never edit `agents-data.js` directly — it is regenerated by the deploy workflow
